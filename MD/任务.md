### 🛠️ 详细任务拆分工作计划（Detailed Task Breakdown）

#### 任务 #1：核心基础数据结构与底座环境代码落地

* **背景**：前缀树过滤引擎需要承载双栈 IP 匹配与多传输层协议（ICMP/TCP/UDP）的分流隔离，且要求业务策略资产与容器拓扑解耦。
* **目标**：完成 `rule_t`、`rule_link_t`、`patricia_node_t` 及 `patricia_table_t` 结构体的物理代码编写与控制面基础分配/初始化底座。
* **执行动作**：
1. 编写头文件对应的底层骨架定义，实现内存分配/释放钩子映射（`patricia_alloc/free`）。
2. 实现按大端网络字节序无伤提取任意特定比特位的快速路宏 `BIT_TEST`。
3. 编写节点基础申请与叶节点规范化填充函数（`alloc_node`, `make_leaf`, `patricia_init_table`）。


* **完成结果**：交付规整、内存对齐的公共头文件基底骨架，控制面基础节点分配函数通过初始编译。

#### 任务 #2：纵向压缩前缀树插入引擎（`patricia_insert`）实现

* **背景**：高性能转发面要求前缀树能够物理压缩无分叉死路，控制面必须实现 1-bit 基数树的动态更新、按位夹逼与路径升级。
* **目标**：全量落地核心插入算法 `patricia_insert`，实现精确网段、根节点升级、子节点升级三大分裂路径，并具备同网段指针去重（`is_rule_duplicate`）能力。
* **执行动作**：
1. 编写非递归遍历查找最邻近终点（`find_any_is_end`，栈深度扩容至 `MAX_DEPTH * 2`）与首个歧义分叉位（`find_first_diff_bit`）的辅助状态机。
2. 编写完整的 `patricia_insert` 主干逻辑，实现精准命中网段时，改写原位覆盖为【横向单链表头插法串联】的多区间并集拓扑。


* **完成结果**：树拓扑纵向单调插入功能闭环，支持同网段多离散端口策略横向链表高效串联，不发生内存越界。

#### 任务 #3：精准前缀摘除与拓扑级联塌陷销毁引擎编码

* **背景**：策略动态下线时需要精准解绑某一物理规则，且当某一网段无任何有效规则留存时，前缀树骨架必须自动折叠合并，防止内存碎片化。
* **目标**：实现基于显式路径追踪的精准删除算法 `patricia_delete` 与可读性高、安全的树销毁函数 `patricia_destroy`。
* **执行动作**：
1. 在 `patricia_delete` 内部构建两倍最大深度的路径与方向追踪栈，实现多协议链表完全清空后的 `is_end=0` 判定及父级单传分支的级联塌陷折叠。
2. 编写 `patricia_destroy` 深度后序递归释放逻辑，确保其只回收树自身拥有的 `rule_link_t` 包装架，不越权触碰释放外部物理资产 `rule_t` 实体。


* **完成结果**：交付完备的策略定向卸载与容器动态缩容、销毁机制，物理释放彻底，拓扑合并维护完全正确。

#### 任务 #4：任意有源 IP 范围（连字符）切碎与合并大数状态机编写

* **背景**：运维人员经常配置非对齐的连字符范围（如 `.3` 到 `.9`），控制面必须自动将其收敛切碎为标准 CIDR 块批量入树，且需要绝对防御 128 位大数全网段溢出地雷。
* **目标**：编写并落地 `patricia_insert_range_v4` 与 `patricia_insert_range_v6` 范围块切分合并引擎。
* **执行动作**：
1. 基于位运算二进制提取构建 IPv4 范围夹逼对齐块计算。
2. 使用双 64 位无符号整数（hi, lo）拼接模拟 128 位大数加减、低位跨边界回绕借位判定。
3. 在 `block_h == 0 && block_lo == 0` 处施加刚性安全拦截报错，物理隔离 `::/0` 导致节点 `bit=-1` 的硬件内存穿透风险。


* **完成结果**：交付双栈万能范围切碎合并底座，完美适配奇葩区间输入，全网通通配溢出风险无伤解决。

#### 任务 #5：字符串控制面工具链与数据面双模快速路径编码

* **背景**：系统需对外提供统一规范的控制面字符串灌单入口，同时数据面要求兼具“广域并集”与“严格最长匹配特判”两种并发包过滤能力。
* **目标**：完成 `acl_add_rule_string/universal` 字符串解析器，并全量落地双模线速转发算法 `acl_lookup` 与 `acl_lookup_lpm`。
* **执行动作**：
1. 采用满足 CWE-120 的物理截断安全拷贝（`strncpy` 配合显式封底）处理控制面 CIDR 和连字符字符串解析。
2. 编写 `acl_lookup`（纵向单向线性下钻伴随横向多路区间盲测的广域并集状态机）。
3. 编写 `acl_lookup_lpm`（解耦的 LPM 下钻定位后、执行仅有一次横向单链表端口测试的局域特判逻辑）。


* **完成结果**：数据面双模快速路径就绪，全面消除了多重条件跳转引发的 CPU 分支预测气泡。

#### 任务 #6：跨平台条件编译适配与全量代码原位集成优化

* **背景**：规则引擎底层依赖网络层协议栈套接字定义，必须在 Windows (Winsock2) 和 Linux (arpa/inet) 双平台下实现无伤编译与外部可见性隔离。
* **目标**：完成 `patricia.c` 的跨平台条件编译整合，消除所有潜存的编译器警告（如 `-Wall -Wextra`），并修正局部可见性。
* **执行动作**：
1. 统一替换老旧边界缺陷函数，全量对齐至标准安全函数 `inet_pton`。
2. 为纯私有内部解析工具函数 `patricia_parse_cidr` 补上 `static` 限制，彻底隔绝多编译单元下的外部全局符号污染。
3. 清理由于符号、有符号/无符号隐式转换带来的细微编译警告隐患。


* **完成结果**：交付符合工业级高品质标准、双平台完全互通、纯净零警告的定版前缀树过滤引擎源码文件。

#### 任务 #7（测试阶段）：高强度全链路 15 项边界冲刷与 ASan 漏洞清账测试

* **背景**：底层系统级组件在多协议横向并集、级联塌陷、大数切碎时，极其容易发生横向链表缠绕、释放后复用（Use-After-Free）或内存越界泄露。
* **目标**：编写高强度 15 项联调级联黑盒/白盒测试脚本，在 `-fsanitize=address`（地址消毒剂）的高压环境下斩获 100% 满分 PASS。
* **执行动作**：
1. 编写 15 个纵向套接、横向串联、边界溢出拦截、精准摘除折叠的极限审计 Case。
2. 重点冲刷验证 Test 13 场景下的独占单节点过滤特判与并集叠加对抗。
3. 深度注入测试 Test 14 / Test 15 场景下的双栈不对齐连字符范围拆分与快速数据面盲测。
4. 严格排查并配套调用 `patricia_delete` 抹除任何因局部残留导致的僵尸野指针，做到测试退出后树骨架完美坍缩合并。


* **完成结果**：交付 15 项全绿 PASS 的深度测试报告，物理堆内存层面实现零泄露、零越界、绝对闭锁，达到商用交付天花板级别。
